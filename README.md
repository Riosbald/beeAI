# beeAI

<img src="docs/assets/beeai-banner.svg" alt="beeAI banner showing AI-powered workflow orchestration and conversational interfaces" width="100%" />

A lightweight AI workflow assistant for bringing structured prompts, automation, and user-friendly chat experiences together in a single product.

## About

beeAI is a practical AI product starting point built for fast experimentation, team workflows, and product demos. It combines a browser-based interface, structured workflow logic, and modular route-based app architecture so you can prototype, test, and iterate quickly.

The project is designed to be easy to run locally, easy to extend, and easy to present to stakeholders without getting bogged down in infrastructure. It is a strong foundation for dashboards, copilots, AI workflow tools, or internal operator assistants.

## Features

- Fast local development workflow
- Route-based app structure for easy extension
- Frontend focused on product demo and UX clarity
- AI-ready architecture for chat, orchestration, and prompt-driven tasks
- Clean visual system with modern card-based UI patterns

## Getting started

```bash
npm install
npm run dev
```

Then open the local app in your browser.
